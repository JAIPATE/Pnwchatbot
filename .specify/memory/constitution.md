# PNW Knowledge Chatbot Constitution

## Core Principles

### 1. Grounded Answers
All answers about university policies, rules, deadlines, and procedures must be grounded in approved university information.
The system must not present unsupported information as official university policy.

### 2. Fail Safely
When the system does not have sufficient reliable information, it must clearly say that it cannot provide a reliable answer.
The system should prefer saying "I don't know" or directing the user to an appropriate university office over generating an unsupported answer.

### 3. Requirements Before Implementation
Each feature must have clear, reviewable, and testable requirements before implementation begins.
Important ambiguities must be resolved by humans rather than silently decided by AI.

## Quality & Governance

- All answers must cite original official PNW documentation sources/URLs where applicable.
- The chatbot must strictly scope responses to currently registered undergraduate and graduate students.
- System outputs must clearly distinguish campus-specific rules (Hammond vs. Westville) when policies differ.
